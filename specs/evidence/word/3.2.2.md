## 1. Clean-Room Reverse Engineering Analysis: Table Auto-Fit Widths

WordprocessingML defines two table layout modes via `<w:tblLayout w:type="...">`:
1. `w:type="fixed"`: Column dimensions strictly follow `<w:tblGrid><w:gridCol w:w="..." /></w:tblGrid>`. Text wraps within the specified widths.
2. `w:type="autofit"` (Default): Column dimensions adapt dynamically according to cell content bounds, multi-column spans (`w:gridSpan`), and the overall target table width (`w:tblW`).

### 1.1 Content Width Boundaries
For each grid column $j \in \{0, \dots, N-1\}$:
1. **Minimum Content Width ($W_{\text{min}}(j)$):**
   The minimum width required to display cell content without intra-word line breaks:
   $$W_{\text{min}}(j) = \max_{r \in \text{rows}} (\text{longest\_unbreakable\_word\_width}(r, j) + \text{cell\_margins}_h)$$
   Subject to a hard minimum floor $W_{\text{min}} \ge 240\text{ twips}$ (12pt).

2. **Maximum Content Width ($W_{\text{max}}(j)$):**
   The width required to render cell paragraphs on a single unwrapped line:
   $$W_{\text{max}}(j) = \max_{r \in \text{rows}} (\text{unwrapped\_paragraph\_width}(r, j) + \text{cell\_margins}_h)$$
   Where $W_{\text{max}}(j) \ge W_{\text{min}}(j)$.

### 1.2 Proportional Distribution Across Target Table Width
Given target table width $W_{\text{target}}$ and available column width:

1. **Interpolation ($W_{\text{min, sum}} \le W_{\text{target}} \le W_{\text{max, sum}}$):**
   $$\alpha = \frac{W_{\text{target}} - \sum_j W_{\text{min}}(j)}{\sum_j W_{\text{max}}(j) - \sum_j W_{\text{min}}(j)}$$
   $$W(j) = W_{\text{min}}(j) + \alpha \cdot (W_{\text{max}}(j) - W_{\text{min}}(j))$$

2. **Proportional Slack Expansion ($W_{\text{target}} > W_{\text{max, sum}}$):**
   $$\text{slack} = W_{\text{target}} - \sum_j W_{\text{max}}(j)$$
   $$W(j) = W_{\text{max}}(j) + \lfloor \frac{\text{slack} \cdot W_{\text{max}}(j)}{\sum_k W_{\text{max}}(k)} \rfloor$$

3. **Proportional Compression ($W_{\text{target}} < W_{\text{min, sum}}$):**
   $$W(j) = \max\left(120, \lfloor \frac{W_{\text{min}}(j) \cdot W_{\text{target}}}{\sum_k W_{\text{min}}(k)} \rfloor\right)$$

### 1.3 Multi-Column Grid Span (`w:gridSpan`) Excess Distribution
When a cell spans $S > 1$ columns from $c_{\text{start}}$ to $c_{\text{end}} = c_{\text{start}} + S$:
- If cell content $W_{\text{cell}} > \sum_{k=c_{\text{start}}}^{c_{\text{end}}-1} W(k)$, the excess $\Delta = W_{\text{cell}} - \sum_{k=c_{\text{start}}}^{c_{\text{end}}-1} W(k)$ is partitioned equally:
  $$\Delta_{\text{per\_col}} = \lfloor \frac{\Delta}{S} \rfloor$$
  $$\forall k \in [c_{\text{start}}, c_{\text{end}}): \quad W(k) \leftarrow W(k) + \Delta_{\text{per\_col}}$$

## 2. Width Unit Conversions & Cell Geometry

### 2.1 Table Width Units (`w:tblW`, `w:tcW`)
- `dxa`: Direct measurements in twips ($1\text{ dxa} = 1\text{ twip} = 1/20\text{ pt}$).
- `pct`: 50ths of a percent ($5000 = 100\%$; $2500 = 50\%$). Twip equivalent is computed against available container width:
  $$W_{\text{twips}} = \lfloor \frac{W_{\text{container}} \cdot \text{val}}{5000} \rfloor$$
- `auto`: Dynamically sized based on content auto-fit.

### 2.2 Horizontal Table Alignment (`w:jc`)
For table of width $W_{\text{table}}$ inside available column width $W_{\text{avail}}$ starting at $X_{\text{col}}$:
- `left` (default): $X_{\text{table}} = X_{\text{col}}$
- `center`: $X_{\text{table}} = X_{\text{col}} + \lfloor \frac{W_{\text{avail}} - W_{\text{table}}}{2} \rfloor$
- `right`: $X_{\text{table}} = X_{\text{col}} + (W_{\text{avail}} - W_{\text{table}})$

### 2.3 Vertical Alignment in Cells (`w:vAlign`)
Inside cell of height $H_{\text{cell}}$ with text bounding height $H_{\text{content}}$:
- `top` (default): Lines start at $Y_{\text{cell}} + \text{margin}_{\text{top}}$.
- `center`: Lines offset by:
  $$\Delta_Y = \lfloor \frac{H_{\text{cell}} - \text{margin}_{\text{top}} - \text{margin}_{\text{bottom}} - H_{\text{content}}}{2} \rfloor$$
- `bottom`: Lines offset by:
  $$\Delta_Y = H_{\text{cell}} - \text{margin}_{\text{top}} - \text{margin}_{\text{bottom}} - H_{\text{content}}$$

## 3. Cross-Page Table Row Breaking & Repeating Headers

### 3.1 Non-Splittable Rows (`w:cantSplit`)
- By default, large rows can split across page boundaries.
- When `<w:cantSplit />` is present, if the row's height $H_{\text{row}} > H_{\text{remaining\_page}}$, the entire row is moved intact to the top of the subsequent page.

### 3.2 Repeating Header Rows (`w:tblHeader`)
- Rows marked with `<w:tblHeader />` serve as table headers.
- When any row in the table advances to a subsequent page, all preceding header rows are replicated at the top of the new page before laying out the page's data rows.
- Replicated rows are tagged with `is_repeated_header: true`.

## 4. Floating DrawingML Object Wrapping (`wp:anchor`)

DrawingML anchors (`wp:anchor`) define floating graphics with surrounding text exclusion zones:

```
                  Col X = 0                                       Col Width
                      +-----------------------------------------------+
                      | Normal text line above floating anchor        |
  Y_mid               | Text line Left |  EXCLUSION ZONE  | Text Right|
                      | Text line Left | (Graphic/Polygon)| Text Right|
                      | Normal text line below floating anchor        |
                      +-----------------------------------------------+
```

### 4.1 Wrap Styles
1. `wrapSquare`: Bounding box of graphic extended by `distL`, `distR`, `distT`, `distB`.
2. `wrapTopAndBottom`: Text cannot flow beside the graphic; the entire column width across $[Y_{\text{top}}, Y_{\text{bottom}}]$ is excluded.
3. `wrapTight` / `wrapThrough`: Text contours around a polygonal boundary (`wp:wrapPolygon`).

### 4.2 Ray-Casting Polygon Edge Intersections
For horizontal text line at midpoint $Y_{\text{mid}}$, ray-cast intersections with polygon edge $(P_1, P_2)$ occur when $Y_{\text{mid}} \in [P_1.y, P_2.y]$:
$$X_{\text{intersect}} = P_1.x + \lfloor \frac{(Y_{\text{mid}} - P_1.y) \cdot (P_2.x - P_1.x)}{P_2.y - P_1.y} \rfloor$$
- Exclusion interval is formed by $[\min(X) - \text{dist}_L, \max(X) + \text{dist}_R]$.
- Available line slices to the left $[X_{\text{col}}, X_{\text{excl, left}}]$ and right $[X_{\text{excl, right}}, X_{\text{col}} + W]$ are provided for text line flow.
