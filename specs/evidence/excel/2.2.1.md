**Governing Standard:** ECMA-376 Part 1 §18.17 (Formulas), ISO/IEC 29500-1  
**Contract Invariants:** GEC-v1.0 (Zero Contamination, Zero Panics, SLAs, Lossless Round-Trip Fidelity)

## 1. Executive Summary

Subphase 2.2.1 delivers the complete lexical analyzer, Pratt operator-precedence parser, AST data model, linear Reverse Polish Notation (RPN) bytecode compiler, and lossless canonical decompiler for ECMA-376 formulas in `crates/excel-engine/src/formula/`.

Key capabilities delivered:
1. **Zero-Panic Pratt Parser:** Top-down operator precedence parser handling all standard ECMA-376 and dynamic array formulas with strictly typed `Result<T, EngineError>`.
2. **Exact Excel Operator Precedence & Associativity:**
   - Range (`:`) > Intersection (` `) > Union (`,`) > Postfix (`%`, `#`) > Prefix (`+`, `-`, `@`) > Power (`^`) > Multiplicative (`*`, `/`) > Additive (`+`, `-`) > Concatenation (`&`) > Comparison (`=`, `<>`, `<`, `<=`, `>`, `>=`).
   - Excel precedence quirk preserved: unary negation binds tighter than exponentiation (`-2^2 = 4`).
   - Power operator is left-associative in accordance with Excel standards (`2^3^2 = 64`).
3. **Comprehensive Reference Support:**
   - A1 notation: relative, absolute, mixed (`A1`, `$A$1`, `A$1`, `$A1`).
   - 2D ranges, whole column ranges (`A:C`, `$A:$B`), whole row ranges (`1:10`, `$1:$5`).
   - R1C1 notation: absolute (`R1C1`), relative (`R[1]C[2]`, `RC[-1]`, `RC`).
   - Sheet prefixes: unquoted (`Sheet1!`), single-quoted with special characters and escaped quotes (`'Sales 2024'!` and `'John''s Data'!`).
   - 3D sheet ranges across worksheets: `Sheet1:Sheet3!A1:B10`, `'Jan:Dec'!B5:B10`.
   - Structured table references: `Table1[Column]`, `Table1[[#Headers],[Sales]]`, `DeptSales[[#Data],[Jan]:[Dec]]`, `[@Amount]`.
   - Dynamic array spill (`#`) and implicit intersection (`@`).
4. **Bytecode Compilation & Lossless Decompilation:**
   - Transforms AST into linear RPN `BytecodeProgram` for stack machine evaluation.
   - Decompiles AST and bytecode back to canonical formula strings with minimal parentheses.
   - Integrated into `CompressedSparsePageGrid` allowing storage and fast retrieval of bytecode alongside raw formula strings.

## 2. Test Suite & Validation Matrix

Validated with 52 comprehensive unit and integration tests in `crates/excel-engine/tests/subphase_2_2_1_test.rs`:
- **Lexical Analysis (Tests 1-19):** Literals, references (A1, R1C1, whole column/row, quoted sheet, 3D sheet, structured tables, spill `#`, implicit intersection `@`, intersection space).
- **Pratt Operator Precedence (Tests 20-27):** Unary `-` over `^`, power left-associativity, `%` postfix, `&` concatenation, comparison chaining, `,` union inside parentheses, space intersection.
- **Function Syntax & Matrix Literals (Tests 28-36):** Single arg, multi arg, empty/omitted args (`IF(A1, 1, )`), nested calls, `_xlfn.` prefixed modern functions, dot-separated statistical functions, 1D/2D array literals (`{1, 2; 3, 4}`).
- **Complex Formula Syntax Trees (Tests 37-43):** Multi-criteria `SUMIFS`, dynamic array `XLOOKUP` with spill, `LET` variables, structured table aggregations, 3D multi-sheet `SUM`, `FILTER` spill, `AREAS` union/intersection.
- **Bytecode & Decompilation (Tests 44-49):** AST compilation to RPN bytecode, binary serialization/deserialization, stack-simulation bytecode decompilation, round-trip equivalence.
- **Robustness & Grid Integration (Tests 50-52):** Zero panics on malformed inputs, CSPG storage/retrieval of formula bytecode, JSON vectors manifest validation.
