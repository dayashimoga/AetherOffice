## 1. Architecture Overview

Subphase 2.1.1 provides the foundational parsing and serialization pipeline for Microsoft Excel `.xlsx` workbooks:

```
                            [ .xlsx Archive ]
                                    │
                                    ▼
                          [ PackageReader ]
                                    │
               ┌────────────────────┼────────────────────┐
               │ (xl/workbook.xml)  │(xl/sharedStrings)  │ (xl/styles.xml)
               ▼                    ▼                    ▼
        [ Workbook Parser ]   [ SST Parser ]      [ Styles Parser ]
               │                    │                    │
               └─────────►  rayon::join  ◄───────────────┘
                                    │
                                    ▼
                         [ ExcelWorkbookPackage ]
                                    │
                        [ UnparsedPartStore ] (Drawings, Macros, Charts, extLst)
```

### 1.1 `xl/workbook.xml` Parser & Serializer
- **Module:** `crates/excel-engine/src/workbook.rs`
- **Key Types:**
  - `Workbook`: Root document container holding sheets, defined names, calculation properties, workbook properties, views, and unmodeled nodes.
  - `SheetRecord`: Worksheet descriptor (`name`, `sheetId`, `r:id`, `state`).
  - `SheetState`: Sheet visibility (`visible`, `hidden`, `veryHidden`).
  - `DefinedName`: Formula names and cell ranges with optional `localSheetId`, `hidden`, and `comment`.
  - `CalcPr`: Engine calculation properties (`calcId`, `calcMode`, `fullCalcOnLoad`, `refMode`, `iterate`, `iterateCount`, `iterateDelta`).
  - `WorkbookPr`: Global workbook properties, including the ECMA-376 `date1904` flag distinguishing the 1900 date system from the 1904 date system.
  - `RawXmlNodeBuffer`: Verbatim retention of extension lists (`extLst`) and unmodeled XML subtrees (e.g., `revisionPtr`, `mc:AlternateContent`).

### 1.2 `xl/sharedStrings.xml` High-Performance SST
- **Module:** `crates/excel-engine/src/shared_strings.rs`
- **Key Types:**
  - `SharedStringTable`: Deduplicated string intern store using `Arc<str>` and lazy reverse index `HashMap<Arc<str>, u32>`.
  - `SharedStringItem`: Supports both plain interned strings and formatted rich text runs (`<r><rPr>...</rPr><t>...</t></r>`).
  - `RichTextRun`: Formatted segment capturing bold, italic, underline, font name, font size, and RGB color.
- **Performance SLA:** Capable of streaming and parsing 1,000,000 shared strings in `< 120 ms` via direct event streaming into preallocated buffers without eager hash map overhead during initial XML load.

### 1.3 `xl/styles.xml` Stylesheet Engine
- **Module:** `crates/excel-engine/src/styles.rs`
- **Key Types:**
  - `StyleSheet`: Complete formatting catalog conforming to ECMA-376 schema order (`numFmts`, `fonts`, `fills`, `borders`, `cellStyleXfs`, `cellXfs`, `cellStyles`, `dxfs`, `tableStyles`, `extLst`).
  - `NumberFormat`: Custom format codes (`numFmtId >= 164`) and built-in format resolution (`0..49`).
  - `Font`: Font name, size, bold, italic, underline, strikethrough, and colors.
  - `Fill`: Pattern fills (`none`, `gray125`, `solid`, etc.) with foreground and background colors.
  - `Border`: Four edge lines + diagonal line with styles (`thin`, `medium`, `double`, `dashed`, etc.) and colors.
  - `CellXf` & `Alignment`: Cell formatting index and alignment (`horizontal`, `vertical`, `wrapText`, `shrinkToFit`, `indent`, `textRotation`).

### 1.4 Parallel Multi-Threaded Package Reader
- **Module:** `crates/excel-engine/src/package.rs`
- Leverages `rayon::join` to parse `workbook.xml`, `sharedStrings.xml`, and `styles.xml` concurrently across worker threads.
- Automatically preserves unknown parts (such as VBA macros, drawings, slicers, and custom XML) inside `UnparsedPartStore`.
