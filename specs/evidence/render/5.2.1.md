## 2. Multi-Document Workspace Tab Bar

The Tab Bar manages concurrent open sessions across Word, Excel, and PowerPoint documents:

### Tab State Invariants:
1. `id`: Unique UUIDv4 string per open document.
2. `doc_type`: `Word` (`.docx`), `Excel` (`.xlsx`), or `PowerPoint` (`.pptx`).
3. `file_path`: Optional local filesystem path (`None` for new unsaved documents).
4. `display_title`: Filename or `Document N` / `Book N` / `Presentation N`.
5. `is_dirty`: Boolean flag indicating unsaved modifications (`true` appends `*` indicator).
6. `active`: Exactly one tab in the tab bar is active (`active_tab_id`). Switching tabs updates the Ribbon context, formula bar visibility, and viewport.

## 4. Excel Formula Bar State Machine

The Formula Bar coordinates between the active spreadsheet grid and text entry:
1. **Name Box:** Displays current active cell in A1 format (`ColToA1(c) + (r + 1)`), or defined range name.
2. **Commit / Cancel Buttons:**
   - Cancel button (`[X]`): Reverts active cell text without committing.
   - Commit button (`[V]`): Parses expression, updates cell value/formula, triggers dependency evaluation graph, and emits command to `CommandBus`.
3. **Live Syntax Tokenizer:** Emits tokens for formula highlighting:
   - Function names: Bold dark blue (`#002060`)
   - Cell references: Color-coded rectangles matching viewport selection outlines (e.g., `A1` blue, `B2` red, `C3` green)
   - String literals: Brown (`#7E3817`)
   - Number literals: Dark green (`#107C41`)

## 5. Keyboard Shortcut Engine & Alt Keytips

### 5.1 Standard Productivity Accelerators
- `Ctrl+C` / `Cmd+C`: Multi-format clipboard copy.
- `Ctrl+X` / `Cmd+X`: Multi-format clipboard cut.
- `Ctrl+V` / `Cmd+V`: Multi-format clipboard paste.
- `Ctrl+Z` / `Cmd+Z`: Transactional Undo.
- `Ctrl+Y` / `Cmd+Y` / `Ctrl+Shift+Z`: Transactional Redo.
- `Ctrl+S` / `Cmd+S`: Save active document.
- `Ctrl+Shift+S`: Save As dialog.
- `Ctrl+O` / `Cmd+O`: Open document dialog.
- `Ctrl+N` / `Cmd+N`: New document of active type.
- `Ctrl+W` / `Cmd+W`: Close active tab.
- `Ctrl+Tab` / `Ctrl+Shift+Tab`: Next / Previous document tab.
- `Ctrl+F` / `Cmd+F`: Open find / navigation panel.

### 5.2 Excel Grid Accelerators
- `F2`: Toggle cell edit mode (move cursor to formula bar or in-place editor).
- `F4`: Toggle reference types (`$A$1` $\rightarrow$ `A$1` $\rightarrow$ `$A1` $\rightarrow$ `A1`) when editing formula.
- `Enter` / `Shift+Enter`: Commit and navigate down / up.
- `Tab` / `Shift+Tab`: Commit and navigate right / left.
- `Arrow Keys`: Navigate active cell.

### 5.3 Alt Keytips Navigation Tree
Pressing `Alt` enters keytip mode and overlays badges on top of Ribbon tabs:
- `Alt + H`: Home tab
- `Alt + N`: Insert tab
- `Alt + P`: Layout tab
- `Alt + M`: Formulas tab
- `Alt + A`: Data tab
- `Alt + S`: Slide Show tab
- `Alt + R`: Review tab
- `Alt + W`: View tab
- `Esc`: Clear / exit keytip mode.

## 6. Tauri IPC Protocol Specification

```
[UI Frontend (TypeScript / HTML5 Canvas / WebGPU)]
        |
        | tauri::invoke(cmd, args)
        v
[Tauri IPC Dispatcher (unified_shell_lib)]
        |
        +---> SessionManager (Tab sessions, active session UUID)
        +---> DocumentEngines:
        |       - WordPackage (crates/word-engine)
        |       - Workbook (crates/excel-engine)
        |       - Presentation (crates/ppt-engine)
        +---> RenderCore:
                - DisplayList Compiler
                - HitTester & CoordinateTransformer
                - CommandBus (Undo / Redo)
                - Headless SVG / Rasterizer Export
```
