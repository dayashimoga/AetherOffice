# Subphase 5.2.2 Evidence: Adaptive Tablet & Mobile UI (Touch Drawers, Stylus Ink, Reflow Mode)

**Governing Standard:** ECMA-376 (ISO/IEC 29500), W3C Pointer Events Level 3, W3C CSS Mobile Safe Area Insets  
**Clean-Room Status:** Pure ECMA-376 Specification and Clean-Room Architecture  

---

## 1. Universal Adaptive Viewport Breakpoints & Form Factors

Under **GEC-v1.0 Article V (Universal Cross-Platform & Adaptive UI Parity)**, the shell adapts dynamically across three canonical device tiers:

| Form Factor | Viewport Width ($W$) | Pointer Modality | Primary Shell Navigation | Ribbon / Tooling Layout |
|---|---|---|---|---|
| **Desktop / Laptop** | $W \ge 1024\text{ px}$ | Fine (`mouse`, `trackpad`) | Multi-Document Tab Bar | Full Multi-Row Contextual Ribbon, Formula Bar, Side Panes |
| **Tablet** | $768\text{ px} \le W < 1024\text{ px}$ | Hybrid / Coarse (`touch`, `stylus`) | Multi-Document Tab Bar | Collapsible Compact Touch Ribbon, Direct Stylus Ink Canvas, Split-Screen |
| **Mobile** | $W < 768\text{ px}$ | Coarse (`touch`) | Bottom Tab Bar / Sheet | Thumb-Zone Swipeable Bottom Command Sheet, Reflow Mode, Card Inspector |

## 2. Safe Area Inset Avoidance & Virtual Keyboard Compensation

Mobile devices with screen notches, home indicator bars, and on-screen virtual keyboards require dynamic geometry adjustment:
- **Safe Area Insets:** $I = (\text{top}, \text{right}, \text{bottom}, \text{left})$ queried via CSS `env(safe-area-inset-*)` or native platform APIs.
- **Available Usable Canvas Height:**
  $$H_{\text{usable}} = H_{\text{screen}} - H_{\text{keyboard}} - I_{\text{top}} - I_{\text{bottom}} - H_{\text{chrome}}$$
- **Active Element Auto-Scroll:** When the virtual keyboard rises ($H_{\text{keyboard}} > 0$), the active caret or cell coordinate $(x_c, y_c)$ is scrolled to maintain an ergonomic clearance of $\ge 24\text{ px}$ above the top of the virtual keyboard.

## 3. Stylus & Pen DrawingML Freehand Ink Layer

For tablet and mobile annotations (Apple Pencil, Samsung S-Pen, Microsoft Surface Pen, universal capacitive styluses):
- **Ink Point Sampling:** $P_i = (x_i, y_i, p_i, t_i)$ where $p_i \in [0.0, 1.0]$ is normalized pressure.
- **Pressure-Dependent Stroke Width:**
  $$w(p) = w_0 \cdot (1.0 + \alpha \cdot (p - 0.5))$$
  with base width $w_0$ (e.g. $2.5\text{ px}$) and sensitivity factor $\alpha = 0.8$.
- **Catmull-Rom Spline Interpolation:** To eliminate angular staircasing without latency, raw sampled points are converted to cubic Bézier control points:
  $$B_1 = P_i + \frac{P_{i+1} - P_{i-1}}{6 \cdot \tau}, \quad B_2 = P_{i+1} - \frac{P_{i+2} - P_i}{6 \cdot \tau}$$
  with tension $\tau = 0.5$.
- **DrawingML Serialization:** Exportable as `<ink:trace>` or `<w:drawing>` vector shapes.

## 4. Word Mobile Reflow Reader Mode

On mobile screens ($< 768\text{ px}$), fixed 8.5" $\times$ 11" page geometry requires horizontal panning that degrades reading comprehension:
- **Reflow Transformation:**
  1. Strips absolute page boundary constraints, margins, and column divisions.
  2. Tables wider than $W_{\text{usable}}$ are collapsed into vertically stacked responsive cards or horizontal swipe carousels.
  3. Continuous vertical rope layout flowed strictly within $W_{\text{usable}}$.
  4. Reader font scale $\lambda \in [1.0, 2.5]$ for high-legibility mobile reading without altering the underlying ECMA-376 document XML.

## 5. Excel Mobile Row Card Inspector

Spreadsheet grids with hundreds of columns are unergonomic for single-thumb data entry on phones:
- **Row-to-Card Mapping:** Converts active row $R$ into an ordered vertical field list:
  $$\text{Card}(R) = \left[ (C_0, \text{Header}_0, \text{Val}_0), (C_1, \text{Header}_1, \text{Val}_1), \dots, (C_m, \text{Header}_m, \text{Val}_m) \right]$$
- **Input Widgets:** Automatically inferred from column data type (Numeric keypad for values, Date picker for dates, Formula editor for formulas).
- **Navigation:** Swipe Up / Down navigates smoothly to Row $R-1$ / Row $R+1$ committing dirty changes atomically through `CommandBus`.

## 6. PowerPoint Touch Laser-Pointer & Presentation Mode

During mobile / tablet presentation projection or screen sharing:
- Touch drag across the slide renders a virtual laser dot:
  $$\text{Center} = (x_t, y_t), \quad R_{\text{core}} = 6\text{ px}, \quad R_{\text{glow}} = 18\text{ px}$$
- Color: High-visibility laser crimson (`#FF1744`) with exponential alpha decay trail for gesture emphasis:
  $$\alpha(t - t_0) = \alpha_0 \cdot e^{-(t - t_0) / 120\text{ ms}}$$
