## 1. Coordinate Transformation & Hit-Testing Engine

### 1.1 Screen-to-World Coordinate Mapping
Let $(x_{\text{screen}}, y_{\text{screen}})$ be physical pointer coordinates in device pixels, $(s_x, s_y)$ be viewport scroll offset, $Z$ be zoom scale factor, and $\text{DPR}$ be device pixel ratio:
$$x_{\text{world}} = \frac{x_{\text{screen}}}{\text{DPR} \cdot Z} + s_x$$
$$y_{\text{world}} = \frac{y_{\text{screen}}}{\text{DPR} \cdot Z} + s_y$$

### 1.2 Office Document Hit-Testing Targets

1. **Word Document (`WordHitTarget`):**
   - **Page Resolution:** Locate target page $P_k$ whose bounding box contains $(x_{\text{world}}, y_{\text{world}})$.
   - **Line & Character Resolution:**
     - Identify text line with vertical range $[y_{\text{line}}, y_{\text{line}} + h_{\text{line}}]$.
     - For glyphs $0, 1, \dots, N-1$ with horizontal advances $[x_0, x_1, \dots, x_N]$:
       - Midpoint split test: if $x_{\text{world}} < \frac{x_i + x_{i+1}}{2}$, caret position is $i$; otherwise $i+1$.
   - **Table Elements:** Distinguish between cell interior, horizontal row border resize ($\pm 3\text{ px}$ threshold), and vertical column border resize ($\pm 3\text{ px}$ threshold).

2. **Excel Worksheet (`ExcelHitTarget`):**
   - **Row & Column Indexing:** Fast binary search across cumulative row heights and column widths:
     $$\text{Row}(y) = \arg\max_r \{Y_r \le y\}, \quad \text{Col}(x) = \arg\max_c \{X_c \le x\}$$
   - **Header Selection:** Clicking $y < Y_{\text{header}}$ selects entire column; $x < X_{\text{header}}$ selects entire row.
   - **Border Resizing:** If $|x - X_{c}| \le 3\text{ px}$, trigger column resize handle; if $|y - Y_{r}| \le 3\text{ px}$, trigger row resize handle.
   - **AutoFill Handle:** A $6 \times 6\text{ px}$ square at the bottom-right corner $(X_{c+1} - 3, Y_{r+1} - 3)$ of the active selection triggers pattern propagation.

3. **PowerPoint Presentation (`PptHitTarget`):**
   - **Shape Body:** Point-in-polygon / point-in-rect query in reverse z-order (top-to-bottom).
   - **8 Bounding Box Resize Handles:**
     $$\text{Handles} = \{\text{TopLeft}, \text{Top}, \text{TopRight}, \text{Right}, \text{BottomRight}, \text{Bottom}, \text{BottomLeft}, \text{Left}\}$$
     Each handle is an $8 \times 8\text{ px}$ touch target.
   - **Rotation Anchor:** Circular handle located $24\text{ px}$ above the `Top` handle. Angle is calculated via:
     $$\theta = \text{atan2}(y_{\text{world}} - cy, x_{\text{world}} - cx)$$

## 2. Selection Models & Overlay Generation

- **Word:**
  - `WordSelection`: `(anchor_offset, active_offset)`. When `anchor == active`, renders a blinking 1.5px vertical caret. When `anchor != active`, renders semi-transparent blue highlight quads (`#0078D733`) behind the selected text.
- **Excel:**
  - `ExcelSelection`: `active_cell: (r, c)`, primary range $(r_1, c_1) \to (r_2, c_2)$, and optional non-contiguous secondary ranges.
  - Renders 2px green border (`#107C41`), semi-transparent green fill (`#107C4126`), and a solid $6\times 6$ square fill handle at $(r_2, c_2)$.
- **PowerPoint:**
  - `PptSelection`: `selected_ids: Vec<u32>`.
  - Renders bounding dashed outline around selected shapes with 8 resize handles and rotation handle.

## 3. Transactional Command Bus & Undo/Redo Engine

The command pattern guarantees atomic transactions and reversible document editing:

```
+-------------------------------------------------------------+
|                        COMMAND BUS                          |
|                                                             |
|   +-----------------------+       +---------------------+   |
|   |      UNDO STACK       |       |     REDO STACK      |   |
|   |  [Cmd 1, Cmd 2, ...]  |       | [Cmd 3, Cmd 4, ...] |   |
|   +-----------------------+       +---------------------+   |
+-------------------------------------------------------------+
          | Execute                     | Undo / Redo
          v                             v
+-------------------------------------------------------------+
|                      DOCUMENT STATE                         |
+-------------------------------------------------------------+
```

### Invariants:
1. `execute(cmd)`:
   - If `cmd` is mergeable with `undo_stack.last()` (e.g. typing characters in sequence within 500ms), merges into the existing command.
   - Otherwise, pushes to `undo_stack` and clears `redo_stack`.
2. `undo()`: Pops command from `undo_stack`, calls `cmd.undo(state)`, pushes to `redo_stack`.
3. `redo()`: Pops command from `redo_stack`, calls `cmd.redo(state)`, pushes to `undo_stack`.
4. `CompoundCommand`: Groups multiple micro-actions (e.g. replacing cell contents + recalculating dependent formula graph) into an atomic unit.

## 4. Multi-Format Clipboard Serializer

Clipboard transfers generate a standardized three-format payload:
1. `text/plain`: Unformatted string (TSV for spreadsheets, plain paragraphs for Word).
2. `text/html`: Styled HTML markup (`<table>`, `<tr>`, `<td>`, `<p style="...">`, `<b>`, `<i>`).
3. `application/vnd.openxmlformats-officedocument.*`: Native ECMA-376 package slice (`w:r`, `c`, `p:sp`) for lossless internal pasting.

## 5. Kinetic Scrolling & Pinch-to-Zoom Inertia Physics

### 5.1 Inertial Scrolling
When a touch or trackpad drag is released with velocity $v_0 \in \mathbb{R}^2$:
$$v(t) = v_0 \cdot \mu^{\Delta t / 16.666}$$
where friction factor $\mu = 0.92$. Motion halts when $|v| < 0.5\text{ px/s}$.

### 5.2 Boundary Rubber-Banding
When scrolled beyond content boundary $x_{\text{min}}$ or $x_{\text{max}}$ by displacement $\Delta x$:
$$F_{\text{spring}} = -k \cdot \Delta x - c \cdot v$$
with spring constant $k = 0.15$ and damping ratio $c = 0.85$, restoring the viewport smoothly to bounds.
